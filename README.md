# Ozzono

App de gestión de ventas para negocio familiar. Permite registrar ventas de cervezas, hielo y servicios Nequi, con soporte para ventas pagadas y fiadas.

## Stack
- React + Vite
- Supabase (PostgreSQL)
- Desplegada en Vercel

## Funcionalidades V1
- Registro de ventas por producto
- Soporte para ventas pagadas y fiadas
- Panel de administración con estadísticas
- Cálculo automático de comisión Nequi

## En desarrollo
- Autenticación multi-usuario
- Filtros por fecha
- Historial de fiados pagados
- Gráficas de ventas
